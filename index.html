🤔 What is debup?

debup is a powerful command-line tool that works like the Arch User Repository (AUR) but for Debian and Ubuntu-based systems. It lets you discover, search, track, install, and upgrade .deb packages directly from GitHub Releases on all architectures, using the familiar APT system you already know.

Whether you're using standard Ubuntu, Linux Mint, Pop!_OS, WSL2 on Windows, or even an Android Linux Terminal, debup makes it incredibly easy to get the latest software from GitHub without hunting through websites or dealing with complicated installation processes.

📥 Download & Install

Getting started with debup is quick and simple:

  1. Visit this link to download the application.
  2. Choose the file that matches your system (look for the one that fits your architecture).
  3. Save the file to a convenient location on your computer.
  4. Open your terminal and navigate to the downloaded file's directory.
  5. Run the installer using: sudo dpkg -i debup_*.deb
  6. After installation, type debup --help to see all available commands!

⚡ Quick Start Guide

# Search for a package
debup search firefox

# Install a package
debup install firefox-developer-edition

# List all tracked packages
debup list

# Update all packages
debup upgrade

# Remove a package
debup remove firefox-developer-edition

That's it! With these simple commands, you can manage all your GitHub-sourced software just like you would with your regular system packages.
